About this chapter

An arithmetic progression is a list of numbers in which you add the same amount each time: savings that grow by ₹50 a week, seats that increase by 2 each row. This chapter shows how to find any term, and the sum of any number of terms, without writing the whole list.

5.2 Arithmetic progressions

✨ Quick recall
What comes next: 5, 9, 13, 17, …? (Answer: 21 — each step adds 4.)
🔑 Key idea · What makes an AP
An AP is a list in which each term is got by adding the same fixed number to the term before it.
That number is the common difference d = a₂ − a₁ = a₃ − a₂ = …
The general form is a, a + d, a + 2d, a + 3d, …
ListDifferencesAP?
3, 7, 11, 154, 4, 4Yes, d = 4
10, 7, 4, 1−3, −3, −3Yes, d = −3
3, 3, 3, 30, 0, 0Yes, d = 0
1, 4, 9, 163, 5, 7No
🔑 Key idea · Three terms in AP
a, b, c are in AP exactly when b − a = c − b, that is 2b = a + c.
The middle term b = [[a + c||2]] is the arithmetic mean of a and c.
For three unknown terms in AP, write them as a − d, a, a + d: their sum is simply 3a.
✏️ Worked example · Find x
2x, (x + 10), (3x + 2) are in AP.
2(x + 10) = 2x + (3x + 2) → 2x + 20 = 5x + 2 → x = 6.
Check: 12, 16, 20 — common difference 4.
✏️ Worked example · Surds can form an AP
√8, √18, √32 = 2√2, 3√2, 4√2.
d = √2, so the next term is 5√2.
⚠️ Common mistake · Checking only one gap
Two terms always have a difference. Check at least two gaps: 1, 3, 6 has gaps 2 and 3, so it is not an AP. And d is always "later term minus earlier term", so 10, 7, 4 has d = −3, not 3.
🧠 Remember in 3 lines
  1. AP: add the same d every time.
  2. d = any term − the term before it.
  3. a, b, c in AP ⇔ 2b = a + c.

Memory hook: "Same Step, every Step" — an AP is a staircase with steps of equal height.

5.3 nth term of an AP

✨ Quick recall
In 2, 7, 12, … how many times do you add 5 to get from the 1st term to the 10th? (Answer: 9 times.)
🔑 Key idea · The nth term
aₙ = a + (n − 1)d, where a is the first term and d the common difference.
To reach the nth term you take (n − 1) steps from the first term.
✏️ Worked example · Which term?
Which term of 21, 18, 15, … is −78?
21 + (n − 1)(−3) = −78 → 3(n − 1) = 99 → n = 34. It is the 34th term.
If n came out as a fraction, the number would not be a term at all.
✏️ Worked example · First negative term
[[81||5]], [[77||5]], [[73||5]], …: aₙ = [[85 − 4n||5]].
aₙ < 0 when n > 21.25, so the 22nd term (−[[3||5]]) is the first negative one.

Finding a and d from given terms

🔑 Key idea · Subtract to find d
aₘ − aₖ = (m − k)d. So if a₁₁ = 35 and a₁₃ = 41, then 2d = 6 and d = 3.
Terms equally far from a middle term average to it: a₅ + a₂₅ = 2a₁₅.
✏️ Worked example · nth term from the end
7, 11, 15, …, 147: reverse it to 147, 143, 139, … with d = −4.
9th term from the end = 147 + 8(−4) = 115.
In general: nth term from the end = l − (n − 1)d.
✏️ Worked example · Counting multiples
Two-digit multiples of 3: 12, 15, …, 99.
99 = 12 + (n − 1) × 3 → n − 1 = 29 → n = 30.
⚠️ Common mistake · Using nd instead of (n − 1)d
The 10th term of 4, 7, 10, … is 4 + 9 × 3 = 31, not 4 + 10 × 3. The first term has already used up one place.
🧠 Remember in 3 lines
  1. aₙ = a + (n − 1)d.
  2. Difference of two terms = (gap in positions) × d.
  3. From the end: start at l and use −d.

Memory hook: "Fence posts" — 10 posts need only 9 gaps, so the 10th term needs only 9 steps of d.

5.4 Sum of the first n terms

✨ Quick recall
Young Gauss added 1 + 2 + … + 100 by pairing 1 + 100, 2 + 99, … What is the total? (Answer: 50 pairs × 101 = 5050.)
🔑 Key idea · Two sum formulas
Sₙ = [[n||2]][2a + (n − 1)d] — when you know a, d and n.
Sₙ = [[n||2]](a + l) — when you know the first term a and last term l.
Both say: number of terms × average of first and last term.
SumFormulaExample
1 + 2 + … + n[[n(n + 1)||2]]first 20: 210
1 + 3 + 5 + … (n odd numbers)n²first 20: 400
2 + 4 + 6 + … (n even numbers)n(n + 1)first 50: 2550
✏️ Worked example · Even numbers between 100 and 200
"Between" leaves out 100 and 200: 102, 104, …, 198, so n = 49.
S = [[49||2]](102 + 198) = 49 × 150 = 7350.
✏️ Worked example · Finding n from the sum
How many terms of 9, 17, 25, … give 636?
[[n||2]][18 + 8(n − 1)] = 636 → 4n² + 5n − 636 = 0 → (n − 12)(4n + 53) = 0.
n must be a natural number, so n = 12.
🔑 Key idea · nth term from Sₙ
aₙ = Sₙ − Sₙ₋₁, and a₁ = S₁.
If Sₙ = n(n − 1), then aₙ = n(n − 1) − (n − 1)(n − 2) = 2n − 2.
✨ Tip · Two answers for n
If both roots of the quadratic are natural numbers, both can be right: for 24, 21, 18, … the sum 78 is reached after 4 terms and again after 13, because terms 5 to 13 add to 0.
⚠️ Common mistakes
Sₙ is a sum, not a term: if Sₙ = n² + n, the 10th term is S₁₀ − S₉ = 20, not S₁₀ = 110.
Reject negative or fractional values of n — a number of terms is always a natural number.
🧠 Remember in 3 lines
  1. Sₙ = [[n||2]](first + last).
  2. Sₙ = [[n||2]][2a + (n − 1)d] when the last term is unknown.
  3. aₙ = Sₙ − Sₙ₋₁.

Memory hook: "Pair them up like Gauss" — first + last, second + second-last, … every pair has the same sum.
